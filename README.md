## Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or physical device

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd flutter_shop_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
